# MPU6050 I2C 예제

MPU6050 6축 관성 측정 장치(IMU)를 사용하는 ESP-IDF 예제입니다.

## 개요

이 예제는 I2C 통신을 통해 MPU6050 센서와 통신하는 방법을 보여줍니다.

MPU6050은 다음을 포함합니다:
- 3축 가속도계 (X, Y, Z)
- 3축 자이로스코프 (X, Y, Z)
- 온도 센서

## 하드웨어 요구사항

ESP32 개발 보드와 MPU6050 센서가 필요합니다.

### 핀 연결

기본 핀 설정 (menuconfig에서 변경 가능):

| ESP32    | MPU6050 |
|----------|---------|
| GPIO 4   | SCL     |
| GPIO 5   | SDA     |
| 3.3V     | VCC     |
| GND      | GND     |

**주의**: MPU6050은 3.3V로 동작합니다. 5V를 연결하지 마세요!

## 빌드 및 실행

```bash
idf.py build
idf.py -p PORT flash monitor
```

시리얼 모니터 종료: `Ctrl + ]`

## 측정 범위 설정

### 가속도계 범위 (Accelerometer)

#### 1. ±2g (기본값) - 일상적인 움직임
- **사용 상황**: 일반적인 기울기 측정, 느린 움직임
- **예시**:
  - 센서를 평평하게 놓으면: `Z ≈ 1.0g` (중력), `X, Y ≈ 0g`
  - 90도 세우면: `X ≈ 1.0g`, `Y, Z ≈ 0g`
  - 거꾸로 놓으면: `Z ≈ -1.0g`
  - 흔들기: `-2g ~ +2g` 범위 내

#### 2. ±4g - 빠른 움직임
- **사용 상황**: 빠르게 흔들기, 운동 동작
- **예시**:
  - 손으로 빠르게 흔들기: `-3g ~ +3g`
  - 공중에 던지기: 순간적으로 `3~4g`

#### 3. ±8g - 격렬한 움직임
- **사용 상황**: 격렬한 운동, 충격 측정
- **예시**:
  - 책상에 센서 치기: 순간적으로 `5~7g`
  - 드론 비행: `-8g ~ +8g`

#### 4. ±16g - 강한 충격
- **사용 상황**: 충돌 감지, 극한 움직임
- **예시**:
  - 바닥에 떨어뜨리기: `10~15g`
  - 자동차 충돌: `10~16g`

**⚠️ 주의**: 범위가 클수록 정밀도는 떨어집니다!
- ±2g: 약 0.0001g 정밀도
- ±16g: 약 0.0008g 정밀도

---

### 자이로스코프 범위 (Gyroscope)

#### 1. ±250°/s (기본값) - 느린 회전
- **사용 상황**: 정밀한 각도 측정, 드론 자세 제어
- **예시**:
  - 가만히 있음: `X, Y, Z ≈ 0°/s`
  - 천천히 돌리기: `10~50°/s`
  - 1초에 반바퀴 회전: `180°/s`

#### 2. ±500°/s - 보통 회전
- **사용 상황**: 일반적인 로봇 움직임
- **예시**:
  - 빠르게 돌리기: `200~400°/s`
  - 1초에 1바퀴 회전: `360°/s`

#### 3. ±1000°/s - 빠른 회전
- **사용 상황**: 스포츠 동작, 빠른 로봇
- **예시**:
  - 손목 스냅: `500~800°/s`
  - 1초에 2바퀴 회전: `720°/s`

#### 4. ±2000°/s - 매우 빠른 회전
- **사용 상황**: 곡예 드론, 격렬한 동작
- **예시**:
  - 드릴처럼 회전: `1000~1800°/s`
  - 1초에 5바퀴 회전: `1800°/s`

```
   가속도(g): X= 0.001 Y= 0.002 Z= 1.000
   자이로(°/s): X= 0.12 Y= -0.34 Z= 0.05

2. 센서를 90도 세우면:
   가속도(g): X= 1.000 Y= 0.001 Z= 0.002
   자이로(°/s): X= 0.10 Y= 0.20 Z= 0.01

3. 센서를 천천히 회전시키면:
   가속도(g): X= 0.5 Y= 0.5 Z= 0.7 (변함)
   자이로(°/s): X= 45.23 Y= 12.50 Z= 67.80 (회전 속도)

4. 센서를 빠르게 흔들면:
   가속도(g): X= -1.8 Y= 1.5 Z= 0.3 (급변)
   자이로(°/s): X= 180.5 Y= -120.3 Z= 90.2
```

## 언제 범위를 바꿔야 할까?

### 범위를 늘려야 하는 경우:
- **값이 최대치에 도달 (포화)**: ±2g인데 계속 ±1.9g 나옴 → ±4g로 변경
- **자이로가 포화**: ±250°/s인데 ±240°/s 나옴 → ±500°/s로 변경

### 범위를 줄여야 하는 경우:
- **정밀도가 필요**: 미세한 기울기 측정 시 ±2g 사용
- **느린 움직임만 측정**: ±250°/s면 충분

## 코드에서 범위 변경 방법

`main/i2c_basic_example_main.c` 파일의 `app_main()` 함수에서:

```c
// 측정 범위 설정 (필요에 따라 변경 가능)
mpu6050_accel_range_t accel_range = ACCEL_RANGE_2G;   // ±2g, ±4g, ±8g, ±16g
mpu6050_gyro_range_t gyro_range = GYRO_RANGE_250;     // ±250, ±500, ±1000, ±2000 °/s
```

사용 가능한 값:
- 가속도계: `ACCEL_RANGE_2G`, `ACCEL_RANGE_4G`, `ACCEL_RANGE_8G`, `ACCEL_RANGE_16G`
- 자이로: `GYRO_RANGE_250`, `GYRO_RANGE_500`, `GYRO_RANGE_1000`, `GYRO_RANGE_2000`

## 문제 해결

### I2C 디바이스를 찾을 수 없습니다
1. **전원 연결 확인**
   - MPU6050 VCC → ESP32 3.3V (5V 아님!)
   - MPU6050 GND → ESP32 GND
   - 전원 LED가 켜져 있는지 확인

2. **I2C 핀 연결 확인**
   - MPU6050 SCL → ESP32 설정된 SCL 핀
   - MPU6050 SDA → ESP32 설정된 SDA 핀

3. **점퍼선/브레드보드 확인**
   - 점퍼선이 제대로 꽂혀 있는지 확인
   - 브레드보드 불량 여부 확인

### WHO_AM_I 레지스터 읽기 실패
- I2C 주소 확인 (기본값: 0x68)
- AD0 핀이 GND에 연결되어 있으면 0x68, VCC에 연결되어 있으면 0x69
