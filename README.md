# New_Workout_Plan

New_Workout_Plan은 카메라와 가속도/심박수 센서를 활용하여 제작된 홈 트레이닝 시스템입니다.

## 1. 시스템 구성

### 1.1. 시스템 구성 요소

#### 활용 부품

1. Jetson nano
2. MQTT
3. MG966R 서보 모터
4. STM32F411R
5. ESP32(ESP-IDF)
6. 가속도센서
7. 심박수 센서(워치)
8. 워치용 디스플레이

#### 구성요소

1. **WatchTower** : 팬틸트 카메라와 MQTT Broker, AI 클라이언트
- Jetson nano
- MQTT Broker
- STM32
- MG966R 서보모터

2. 심박수 측정 및 제어용 **스마트 워치**
- ESP32
- 심박수 센서
- 워치용 디스플레이

3. 운동 동작 측정용 **조이스틱**
- ESP32
- 가속도 센서
- 진동모터

4. **서버**
- 자세 인식 AI 연산용 서버
- Yolo pose?

## 2. 소프트웨어 구성
1. 서버
- 자세 인식 AI 연산용 AI 서버
- Flask로 AI 클라이언트와 통신함.
- 사진 또는 영상을 수신
- 송신은 분석 데이터

2. WatchTower
- MQTT의 Broker(서버)
- 워치와 조이스틱의 토픽을 구독함.
- 카메라 연결되고 사진과 영상을 서버에 전송함.
- 화면과 연결하고 화면을 출력
- 여러 그래픽 요소를 같이 출력

- 워치와 조이스틱에서 전달받은 데이터를 바탕으로 결과화면 생성

3. 워치
- ESP32, ESP-IDF, FreeRTOS 사용
- MQTT의 토픽 발행
- 심박수 측정 후, WatchTower로 전달
- I2C - 화면/심박수, SPI - 터치

4. 조이스틱
- 가속도 센서의 데이터를 WatchTower로 전달
- 운동 보조기구로 활용
